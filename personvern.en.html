Privacy Statement

Microdata Script Runner is a free, public version with no login and no accounts.

Last updated: 2026-10-08.

1. What is this?

Microdata Script Runner is a hobby project run by Hans Olav Melberg that helps users write and run code against microdata.no syntax, Python, and R directly in the browser. This version requires no login and no account. Your script, any datasets you load, and the run results stay in your browser by default. They leave it only in the cases described below: when you use the AI features (section 2), and when the app fetches libraries or data from the web, or you connect GitHub yourself (section 4).

2. What happens when you use the AI assistant?

The AI features (code suggestions, interpreting results, privacy assessment, web search) require you to paste your own API key under AI settings. You choose which provider that key belongs to: Anthropic is the default, but you may instead supply OpenAI, Mistral, or any other service with an OpenAI-compatible API. When you do:

  • The key is stored only locally in your browser (localStorage) and sent as a header (X-Anthropic-Key or X-Llm-Key) to our server, which forwards it directly to the provider you selected for that one request. The key is never stored or logged on the server — not even in the temporary job storage described below.
  • What is sent to the provider depends on the feature, and may include: your question; the script in the editor (when you tick the box to include it, and always for result interpretation and the privacy assessment); run results and output (for result interpretation, and when the assistant itself runs a script in the emulator — run_code — and reads the result); earlier messages in the conversation (the conversation history); custom instructions you have entered; and the context you write in the privacy assessment. Values in key(...) are masked as key(***) in the browser before anything is sent.
  • Temporary storage of AI answers. The AI assistant's answers are produced by a background job on the server. The job temporarily stores the streamed answer, the scripts the model writes, and the conversation state (which contains the question, the script, run results and the conversation history) in Netlify Blobs, so the browser can fetch the answer as it is produced and resume after a network drop. An automatic cleanup runs every hour and deletes jobs older than one hour, so the content is normally kept for 1–2 hours. Result interpretation and the privacy assessment are streamed straight back and are not stored.
  • If you chose a provider other than Anthropic, the request — and the key — goes to the API address you entered in settings, and is handled under that service's terms and privacy policy. We have no agreement with, and no control over, a provider you select this way.
  • Your IP address and rate limiting. To prevent abuse, the server counts calls to the /api/ endpoints per IP address (for IPv6: per /64 network) and endpoint. The counters are stored in Netlify Blobs: for each combination of endpoint and IP address, the address is stored (as part of the key) together with the times of the calls in the last hour. Older times are removed the next time the same address makes a call, but the entry with the IP address itself is not deleted automatically — it stays until it is overwritten by a new call from the same address.
  • Calls authenticated with the owner's personal access password (the owner's own use) are recorded in an error journal in Netlify Blobs for debugging. Calls with your own API key or a shared access password are never journaled.
  • Usage (tokens/cost) is billed to your own account with the provider you selected — we do not see or store payment information.

3. Cookies and local storage

The app uses no cookies. It uses localStorage in your own browser to remember settings and work: API key or access password, chosen AI provider and model, quality level, GitHub token and profiles (if you have connected GitHub), drafts and recently used scripts, chosen mode and theme. None of this is sent to us beyond what is described in sections 2 and 4. A service worker stores fixed versions of program libraries (such as Pyodide and Plotly) in the browser's Cache Storage for faster start-up; datasets you load are not stored there.

4. Sharing with third parties and other outbound traffic

We do not sell or rent out data. When you use the AI features, the content described in section 2 is shared with:

  • The AI provider you selected in settings — to generate the response. With no explicit choice this is Anthropic (USA); if you supplied a different provider, it is that one, at the API address you entered.
  • Netlify (hosting for the app and server functions, and the storage in Netlify Blobs).

In addition, the browser connects to these services. They see your IP address and which address is fetched, as with any website:

  • Libraries from CDNs: cdn.jsdelivr.net (Pyodide, markdown-it, Tabulator, Brython and Python packages), cdn.plot.ly (Plotly), pypi.org and files.pythonhosted.org (Python packages installed on demand) and webr.r-wasm.org / repo.r-wasm.org (R mode).
  • The names registry and GitHub links: If you open a link with a short name (e.g. #my-dashboard), the name is looked up in a registry on raw.githubusercontent.com. Links to scripts or data on GitHub are also fetched from there.
  • Data you load: When a script loads data from a URL, the browser fetches it directly from that address. If the source blocks such fetches (CORS), the request instead goes through the app's proxy /api/hent: the server fetches the address for you and returns the content without storing it. As proof of access, the browser then sends your Anthropic key in the X-Anthropic-Key header to our server; the proxy only checks the key's format and does not pass it on to the data source. These calls count towards the rate limiting described in section 2.
  • GitHub (api.github.com): If you connect GitHub with your own access token, the browser talks directly to GitHub's API to list, fetch and save files in the repositories you choose. The token is stored only in the browser and sent only to GitHub. Scripts you save end up in your repository, with key(...) values masked.

5. Your rights

We have no accounts and do not store content permanently: the AI jobs in Netlify Blobs are deleted after 1–2 hours. What remains over time are the rate-limiting entries with IP address and times (section 2). If you want access to or deletion of such data, or have other questions, please get in touch (see below). You may also file a complaint with the Norwegian Data Protection Authority (datatilsynet.no).
