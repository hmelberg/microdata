Svar: Forskjellen på keep if og drop if

keep if og drop if er komplementære kommandoer som filtrerer observasjoner (rader) i datasettet, men i motsatt retning:

keep if <betingelse>

Beholder kun radene der betingelsen er sann, og sletter alle andre.

Eksempel:

keep if alder >= 18

📋 Copy

Etter denne kommandoen inneholder datasettet bare personer som er 18 år eller eldre.

drop if <betingelse>

Sletter radene der betingelsen er sann, og beholder alle andre.

Eksempel:

drop if alder < 18

📋 Copy

Etter denne kommandoen er alle personer under 18 år fjernet fra datasettet.

Praktisk sammenligning
Kommando	Effekt	Eksempel
keep if kjonn == '1'	Beholder bare menn	Alle kvinner er fjernet
drop if kjonn == '2'	Sletter alle kvinner	Samme resultat — bare menn igjen
Viktig merknad: Personvern (T1-regel)

Begge kommandoer er underlagt T1-regelen: etter filtreringen må populasjonen ha minst 1 000 enheter. Hvis betingelsen din ville redusere datasettet til færre enn 1 000 rader, avviser plattformen kommandoen med en feilmelding.

Når bruke hvilken?

Bruk keep if når du tenker positivt («jeg vil ha X»)
Bruk drop if når du tenker negativt («jeg vil ikke ha Y»)

Begge er like gyldige — valget er stilistisk og avhenger av hva som er mest naturlig å uttrykke i din analyse.
