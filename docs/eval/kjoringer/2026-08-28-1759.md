# Svar: `keep if` vs `drop if`

Begge kommandoer filtrerer observasjoner (rader) i datasettet basert på en betingelse, men de virker i motsatt retning:

## `keep if <betingelse>`
**Behold** kun observasjoner som oppfyller betingelsen — **slett alle andre**.

Eksempel:
```microdata
keep if alder >= 18
```
Etter denne kommandoen består datasettet kun av personer med alder ≥ 18 år.

## `drop if <betingelse>`
**Fjern** observasjoner som oppfyller betingelsen — **behold alle andre**.

Eksempel:
```microdata
drop if alder < 18
```
Etter denne kommandoen består datasettet av alle personer UNNTATT dem med alder < 18 år.

## Semantisk ekvivalens
Disse to kommandoene er **logisk ekvivalente**:
- `keep if alder >= 18` = `drop if alder < 18`
- `keep if kjonn == '1'` = `drop if kjonn != '1'`

## Valg i praksis
- Bruk **`keep if`** når du tydelig definerer **hvem du vil ha med** (fokus på ønsket populasjon).
- Bruk **`drop if`** når du tydelig definerer **hvem du vil ha bort** (fokus på eksklusjoner).

Begge endrer datasettet **permanent** — de etterfølgende kommandoene arbeider med det filtrerte datasettet.
