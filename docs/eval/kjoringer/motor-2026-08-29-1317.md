```
require no.ssb.fdb:53 as db

create-dataset children
import db/BEFOLKNING_KJOENN as kjonn
import db/BEFOLKNING_FOEDSELS_AAR_MND as faarmnd
generate age2020 = 2020 - int(faarmnd/100)
keep if (age2020 >= 25) & (age2020 <= 55)
import db/BEFOLKNING_FAR_FNR as fnr_far
import db/BEFOLKNING_MOR_FNR as fnr_mor
import db/INNTEKT_WYRKINNT 2014-12-31 as yrkinnt2014
import db/INNTEKT_WYRKINNT 2020-12-31 as yrkinnt2020
replace yrkinnt2014 = 0 if sysmiss(yrkinnt2014)
replace yrkinnt2020 = 0 if sysmiss(yrkinnt2020)

create-dataset parentinfo
import db/BEFOLKNING_KJOENN as kjonn2
import db/UFOERP2011FDT_MOTTAK 2013-01-01 as ufore_pre
import db/UFOERP2011FDT_MOTTAK 2020-01-01 as ufore_post
generate parent_onset_far = 0
replace parent_onset_far = 1 if (ufore_pre == '0') & (ufore_post == '1')
clone-variables parent_onset_far -> parent_onset_mor
merge parent_onset_far into children on fnr_far
merge parent_onset_mor into children on fnr_mor

use children
generate parent_sick = 0
replace parent_sick = 1 if parent_onset_far == 1
replace parent_sick = 1 if parent_onset_mor == 1
drop if (sysmiss(parent_onset_far)) & (sysmiss(parent_onset_mor))
tabulate parent_sick

reshape-to-panel yrkinnt
generate post = 0
replace post = 1 if panel@date == 2020

// Rå DiD (uten kontroller)
regress-panel-diff yrkinnt parent_sick post

// Justert DiD (kontroller for alder og kjønn)
regress-panel-diff yrkinnt parent_sick post age2020 i.kjonn

```

I den syntetiske øvingsdatabasen finner jeg ingen statistisk signifikant effekt av at en forelder blir syk på det voksne barnets yrkesinntekt. Diff-in-diff-estimatet (ATET) er -13 044 kr per år (både i rå og alders-/kjønnsjustert modell), med p ≈ 0,73–0,74 — langt fra signifikant. Konfidensintervallet (-90 700 til +64 600) er bredt og inkluderer null tydelig.

(Alle tall er fra syntetiske øvingsdata og skal ikke tolkes som faktiske register-tall.)

Slik leser du utskriften
Design: "Foreldre blir syk" er proxyet med nytt uføretrygd-mottak (UFOERP2011FDT_MOTTAK gikk fra 0 i 2013 til 1 i 2020) hos far eller mor. Barnets yrkesinntekt (INNTEKT_WYRKINNT) er målt i 2014 (før) og 2020 (etter) i et to-periode panel.
Gruppestørrelser (tabulate parent_sick): 199 barn med foreldre-sykdomshendelse mot 4 786 kontrollbarn — 4 985 totalt, over T1-grensen (≥1000).
Regresjonstabellen (regress-panel-diff yrkinnt parent_sick post):
const (509 100 kr) = kontrollgruppens gjennomsnittsinntekt i 2014.
post (+114 400 kr, p<0.001) = generell inntektsvekst 2014→2020 for kontrollgruppen (konjunktur/livsløp).
parent_sick (+33 200 kr, p=0.235) = nivåforskjell FØR sykdomshendelsen — ikke signifikant, men antyder at "behandlingsgruppen" i utgangspunktet hadde noe høyere inntekt (viktig å merke seg for parallelle trender-antakelsen).
parent_sick_x_post = ATET = -13 044 kr (p=0.742) — selve effekten: barn med en syk forelder fikk 13 000 kr MINDRE inntektsvekst enn kontrollgruppen, men effekten er ikke skilt fra null.
Justering for age2020 og i.kjonn endrer estimatet marginalt (samme koeffisient, p flytter fra 0.742 til 0.729) — konfunder-justeringen har lite å si her, sannsynligvis fordi utvalget er syntetisk/tilfeldig generert uten innebygd sammenheng.
Vurderinger og forslag

Mekanismer man forventer i ekte data:

Direkte omsorgsbelastning (redusert arbeidstid/permisjon) hos voksne barn som må bistå syke foreldre.
Indirekte inntektstap via arv/overføringer som forsvinner, eller psykisk belastning.
Motsatt fortegn mulig: barn kan øke arbeidstilbudet for å kompensere for tapt foreldreinntekt i husholdningen.

Forbehold ved denne identifikasjonsstrategien:

Proxy-validitet: Uføretrygd-mottak fanger bare alvorlig, varig arbeidsudyktighet — ikke akutt sykdom, kreft under behandling, eller sykdom som ikke fører til uføretrygd. Vurder å supplere med ARBAVKLARPFDT_MOTTAK (arbeidsavklaringspenger, tidligere fase) eller NPR-sykehusinnleggelser (HOVEDTILSTAND1/INNDATO) som alternative helsesignaler — merk at NPR-katalogen her kun dekker ett år (2023), så den egner seg ikke til før/etter-design uten lengre tidsserie.
Parallelle trender: parent_sick-koeffisienten før behandling (33 200 kr, p=0.235) antyder en viss forskjell i utgangsnivå — bør sjekkes med en placebo-periode (f.eks. 2010 vs 2014) før man stoler på DiD.
Seleksjon i lenkingen: Bare barn med kjent fnr_far/fnr_mor beholdes; skjevheter i hvem som har registrerte foreldrekoblinger kan påvirke resultatet.
Heterogenitet man bør undersøke videre (krever nok observasjoner per celle): kjønn på det syke foreldre-leddet (far vs. mor), barnets sivilstatus/husholdningstype (BEFOLKNING_REGSTAT_FAMTYP), og om barnet bor i samme kommune som forelderen (geografisk nærhet til omsorgsansvar).
Videre analyse: regress-panel depvar ..., fe med individ-faste effekter over flere år, eller en cox/event-study rundt eksakt onset-tidspunkt (via import-event for finere tidsoppløsning), ville gitt et sterkere design enn denne enkle to-periodes DiD-en.
