Svar: Collapse vs. Summarize

Dette er et metodespørsmål uten kjøring, så jeg svarer direkte:

Kort sammenligning
Aspekt	summarize	collapse
Hva den gjør	Viser univariat statistikk (mean, sd, min, max, osv.) for variabler	Aggregerer datasettet til et høyere grupperings nivå
Hvordan datasettet påvirkes	Datasettet forblir uendret — bare tabellvis output	Datasettet ERSTATTES med aggregerte data (destruktiv operasjon)
Antall rader etter	Samme antall rader som før	Én rad per gruppe (eller færre hvis by() brukt)
Variabler som overlever	Kun de som ble beregnet	Only aggregerte variabler + by-variabelen
Typisk bruk	Rask inspeksjon av data for analyse	Bygg et aggregert datasett for videre analyse/plotting
Eksempler
summarize — inspeksjon
summarize inntekt alder if kjonn == '1'
// Viser: N, mean, sd, min, max for menn
// Datasettet er uendret etterpå

📋 Copy
collapse — aggregering til nytt datasett
collapse (mean) inntekt -> snitt_innt (count) inntekt -> n_personer, by(aldersgruppe)
// Datasettet blir nå: 
//   - én rad per aldersgruppe
//   - variabler: aldersgruppe, snitt_innt, n_personer
// Alle andre variabler er borte

📋 Copy
Når bruke hva?
summarize: Du vil se gjennomsnitt, spredning osv. uten å endre datasettet — brukes før eller under analyse for å forstå rohdataene.
collapse: Du vil bygge et nytt, aggregert datasett som basis for regresjon, plotting eller videre merge — en destructive operasjon som oftest følges av use <dataset> for å arbeide videre med aggregatene.

Personvern-notat: collapse winsoriseres automatisk (1%/99%) når by()-nøkkelen IKKE er pseudonymisert (f.eks. by(kommune) eller by(aldersgruppe)), som del av avsløringskontroll.
